# Milestone 2 release notes

ProtoTower now has a public, read-only catalog of versioned synthetic wellness
protocols. Visitors can browse the latest published version of active protocols and
open a structured detail page with ordered steps, cautions, references, and a clear
educational-information disclaimer.

The release adds provider-neutral domain validation, PostgreSQL constraints,
row-level security, explicit grants, published-version immutability, deterministic
synthetic seeds, generated database types, a Fetch API PostgREST adapter, resilient
unavailable states, and expanded unit, pgTAP, browser, accessibility, security, and
performance coverage.

The public brand is now ProtoTower. ProtoTower.ai is reserved but not connected to
production in this milestone. Existing ProtoStack repository, package, Worker, and
staging identifiers remain stable.

No authentication, authoring or publishing UI, personal tower builder, tracking,
outcomes, AI, analytics, notifications, email, payments, or MCP is included.
